# Weather App in JavaScript

A clean and responsive Weather Application built using HTML, CSS, and vanilla JavaScript. Powered by the OpenWeatherMap API to deliver real-time weather information and device geolocation forecasts.

## Features

- 🌤️ **Real-Time Weather Data**: Current temperature, weather description, feels-like temperature, and humidity.
- 📍 **Device Geolocation**: Quickly fetch local weather using the "Get Device Location" button.
- 🔍 **City Search**: Search weather for any city worldwide by pressing Enter.
- 🎨 **Dynamic Weather Icons**: Weather icons change dynamically based on the current conditions (clear, clouds, rain, snow, storm, haze).
- 📱 **Responsive Design**: Designed to work cleanly across mobile and desktop screens.

## How to Run

1. Clone or download this repository.
2. Open `index.html` directly in your web browser (or use Live Server in VS Code).
3. Enter a city name and press Enter, or click **Get Device Location** to view current weather data.
